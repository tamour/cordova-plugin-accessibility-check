# cordova-plugin-accessibility-check

Cordova plugin for detecting Android Accessibility settings, active accessibility services, and enabled accessibility services.

Created by Tamour Ahmad.

---

## Features

- Check whether Android Accessibility is globally enabled
- Check whether accessibility services are currently active
- Retrieve all enabled accessibility services
- Lightweight and easy to integrate
- Supports Android platform

---

## Installation

Install the plugin using Cordova CLI:

```bash
cordova plugin add cordova-plugin-accessibility-check
